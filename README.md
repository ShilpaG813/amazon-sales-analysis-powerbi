# Amazon Sales Analysis Dashboard

An interactive business intelligence dashboard developed using Microsoft Power BI to analyze Amazon product sales performance, category contribution, product trends, and customer review patterns.

## Project Overview

This project focuses on transforming raw Amazon sales data into an interactive analytical dashboard that provides insights into sales performance across different time periods, product categories, and individual products.

The dashboard is designed to help understand:

- Overall sales performance
- Monthly and weekly sales trends
- Product category contribution
- Top-performing products
- Customer review patterns

## Objectives

- Analyze sales performance over time
- Identify high-performing product categories
- Identify top products based on sales
- Analyze product review distribution
- Create interactive KPIs and visualizations for business analysis
- Present data-driven insights through an intuitive Power BI dashboard

## Tools & Technologies

- **Microsoft Power BI**
- **Power Query**
- **DAX**
- **Microsoft Excel**
- **Data Cleaning & Transformation**
- **Data Analysis**
- **Data Visualization**

## Data Preparation

The source data was prepared and transformed using Power Query before being used for analysis.

Key data preparation activities included:

- Data cleaning and transformation
- Data type handling
- Preparing fields required for analysis
- Structuring the dataset for Power BI visualization

## Key Metrics

The dashboard includes the following key performance indicators:

- **YTD Sales**
- **QTD Sales**
- **YTD Products Sold**
- **YTD Reviews**
- **Category-wise Sales Contribution**

## Dashboard Analysis

### Sales Trend Analysis

The dashboard provides monthly and weekly sales analysis to identify changes and patterns in sales performance over time.

### Product Category Analysis

Category-level analysis is used to compare sales contribution across different product categories and identify categories with higher sales performance.

### Product Analysis

The dashboard highlights the top-performing products based on YTD sales and identifies products with high customer review volumes.

## Dashboard Features

- Interactive product category filter
- Quarter filter
- Monthly sales trend analysis
- Weekly sales analysis
- Product category sales analysis
- Top 5 products by YTD sales
- Top 5 products by YTD reviews
- Interactive KPI cards
- DAX-based calculations
